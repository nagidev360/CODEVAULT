# CODEVAULT ZD230 Direct Print

Printer: **ZDesigner ZD230-203dpi ZPL**

1. Install Node.js on the Windows PC connected to the ZD230.
2. Confirm the printer name is exactly `ZDesigner ZD230-203dpi ZPL`.
3. Double-click `local-print/run-print-bridge.bat`.
4. Keep the command window open.
5. Open CODEVAULT and click **DIRECT ZD230**.

The bridge listens only on 127.0.0.1:9100 and sends RAW ZPL through the Windows printer queue.
