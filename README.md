# CODEVAULT

Free Render-ready diamond CSV workspace.

## Features
- NAGI.KEY verification through a server-side proxy
- 3 CSV upload types
- 3 downloadable CSV templates
- Browser-side CSV validation
- CSV contents are not sent to the server

## Render
Start command: npm start
Optional environment variable: NAGI_KEY_VERIFY=https://nagi-key-4sli.onrender.com/api/key/verify
